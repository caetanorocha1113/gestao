# Gestão e Agendamento de Lista de Tarefas

React, Node + Express + Prisma e PostgreSQL.

## Como rodar

Backend (porta 3001)
```bash
cd backend
npm install
npx prisma dev
npm run generate
npm run db:init
npm run dev
```

Frontend (porta 5173)
```bash
cd frontend
npm install
npm run dev
```
